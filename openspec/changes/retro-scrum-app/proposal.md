# Change: retro-scrum-app

## Proposal

See [project-level proposal](../../proposal.md) for full context.

This change implements the complete retro-scrum-app: a multi-tenant SaaS for collaborative Scrum Retrospectives.

### Key Capabilities
1. `auth-and-onboarding` — Registro, login, creación de empresa
2. `subscription-plans` — Planes, límites, tracking IA
3. `team-management` — Equipos, invitaciones, roles
4. `sala-management` — CRUD de salas por equipo
5. `real-time-board` — Tablero 4 columnas con Realtime
6. `card-management` — Tarjetas, drag-drop
7. `ai-clustering` — Agrupación semántica por IA
8. `export-markdown` — Export a .md
9. `export-pdf` — Export a PDF via print CSS

🟡 Proposed — pending spec phase
